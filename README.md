# NEXORA — Premium Digital Studio

Responsive luxury black-and-gold agency website. Static HTML/CSS/JS; no build step required.

## Before launch
- Replace hello@nexora.studio in index.html with your real business email.
- Portfolio tiles are clearly marked as concept showcases, not client work.
- Confirm brand name, domain and social handle availability before commercial use.

## Deploy
Served as a static site. Publish the repository root; build command can be blank.
